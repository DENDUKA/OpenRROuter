# Исправление: Control token не маппится в gRPC-ответе ListRouterNodes

## Проблема

Каждую минуту CollectorService логирует **4 Warning'а** (2 ноды × 2 коллектора: `NodeCatalogCollector` + `NodeQuotaCollector`):

```
Control token is not set for endpoint 'http://f9router/'.
Control token is not set for endpoint 'http://f9router-2/'.
```

Ошибки повторяются бесконечно — токен всегда пустой.

## Корневая причина

В `GrpcRouterControlPlaneService.MapNodeSummary` (**строка 471-482**) поле `ControlToken` **не маппится** из доменной сущности `RouterNode` в proto-сообщение `RouterNodeSummary`:

```csharp
// src/OpenRussiaRouter.ControlPlane/Infrastructure/Grpc/GrpcRouterControlPlaneService.cs:471
private static RouterNodeSummary MapNodeSummary(RouterNode node) =>
    new()
    {
        NodeId = node.Id,
        Name = node.Name,
        EndpointUrl = node.EndpointUrl.ToString(),
        Status = ...,
        InFlightRequests = node.InFlightRequests,
        LastCheckedAtUtc = ...,
        CapacityWeight = node.CapacityWeight,
        LastHealthErrorCode = ...
        // ← ControlToken ОТСУТСТВУЕТ
    };
```

В proto3 строковые поля по умолчанию = `""`. CollectorService получает пустой токен → `NodeAdminClient.SendAsync` (строка 39-40) бросает `InvalidOperationException`.

## Цепочка данных

```
RouterNode (ControlToken валидный)
  → MapNodeSummary() — ControlToken теряется ← БАГ
    → ListRouterNodesResponse (ControlToken = "")
      → NodeListProvider → CollectorNode (ControlToken = "")
        → NodeCatalogCollector / NodeQuotaCollector → NodeAdminClient.SendAsync
          → InvalidOperationException
```

## Исправление

**Файл:** `src/OpenRussiaRouter.ControlPlane/Infrastructure/Grpc/GrpcRouterControlPlaneService.cs`

Добавить строку `ControlToken = node.ControlToken` в метод `MapNodeSummary`:

```csharp
private static Contracts.Grpc.ControlPlane.V1.RouterNodeSummary MapNodeSummary(RouterNode node) =>
    new()
    {
        NodeId = node.Id,
        Name = node.Name,
        EndpointUrl = node.EndpointUrl.ToString(),
        Status = (node.Enabled ? node.Status : RouterNodeStatus.Disabled).ToString(),
        InFlightRequests = node.InFlightRequests,
        LastCheckedAtUtc = node.LastCheckedAtUtc?.ToString("O") ?? string.Empty,
        ControlToken = node.ControlToken,          // ← ДОБАВИТЬ
        CapacityWeight = node.CapacityWeight,
        LastHealthErrorCode = node.LastHealthErrorCode ?? string.Empty
    };
```

Proto-сообщение `RouterNodeSummary` уже содержит поле `control_token = 7` (строка 128 в `control-plane.proto`), CollectorService уже ожидает его — изменений в proto и клиентах не требуется.

## Проверка

1. `dotnet build OpenRussiaRouter.sln` — убедиться что нет ошибок компиляции
2. `dotnet test OpenRussiaRouter.sln` — все тесты проходят
3. Ручная: запустить CollectorService → в логах ошибки `Control token is not set` должны прекратиться
