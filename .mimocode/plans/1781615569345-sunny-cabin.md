# План: Поддержка Image Generation в OpenRussiaRouter

## Контекст

- F9Router (нода) **полностью поддерживает** `/v1/images/generations` с 17+ провайдерами
- OpenRussiaRouter gateway **не имеет** этого эндпоинта
- **Биллинг пока не трогаем** — только добавляем проксирование

### Формат ответа F9Router

```json
{
  "created": 1781624619,
  "data": [
    {
      "b64_json": "iVBORw0KGgoAAAANSUhEUg..."
    }
  ]
}
```

**Нет** поля `usage` — только `created` и `data[0].b64_json`.

## Изменения

### 1. ApiGateway: эндпоинт `/v1/images/generations`

**Файл:** `src/OpenRussiaRouter.ApiGateway/Application/Extensions/ApiGatewayExtensions.cs`
- Зарегистрировать: `app.MapPost("/v1/images/generations", (handler, ctx) => handler.HandleAsync(ctx));`
- Зарегистрировать `ImageGenerationHandler` в DI

**Файл:** `src/OpenRussiaRouter.ApiGateway/Application/Endpoints/ImageGenerationHandler.cs` (НОВЫЙ)
- Аналог `ChatCompletionHandler`, но **только non-streaming**
- Flow:
  1. Читаем JSON тело запроса
  2. Извлекаем `model` из тела
  3. `pipeline.AuthorizeAndAcquireLeaseAsync` — авторизация + баланс + лизинг ноды
  4. `SseRequestPatcher.PatchModel` — замена model на routerModelId
  5. `routerProxy.SendImageGenerationAsync(lease, patchedJson, ...)` — прокси на `/v1/images/generations`
  6. Релиз лиза (`completed`/`failed`)
  7. Retry при `StatusCode >= 400` (как в ChatCompletionHandler)
  8. Ответ клиенту (уже OpenAI-совместимый JSON от F9Router)

### 2. Router: проксирование на `/v1/images/generations`

**Файл:** `src/OpenRussiaRouter.ApiGateway/Router/IRouterProxyProvider.cs`
- Добавить метод `SendImageGenerationAsync`

**Файл:** `src/OpenRussiaRouter.ApiGateway/Router/YarpRouterProxyProvider.cs`
- Реализовать `SendImageGenerationAsync` — аналог `SendChatCompletionAsync`, но:
  - `path = "/v1/images/generations"` вместо `/v1/chat/completions`
  - Используем `ForwardingHttpClient` (YARP) для non-streaming

### 3. Регистрация endpoint

**Файл:** `src/OpenRussiaRouter.ApiGateway/Application/Extensions/ApiGatewayExtensions.cs`
- Добавить в `MapGatewayEndpoints`:

```csharp
app.MapPost("/v1/images/generations", (handler, ctx) => handler.HandleAsync(ctx));
```
