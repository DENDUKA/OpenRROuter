# Поддержка 9Router Combos (Model Fallback) в OpenRussiaRouter

## Проблема

9Router поддерживает **combos** — виртуальные модели с fallback между реальными моделями. Комбо хранятся в таблице `combos` в SQLite ноды и отдаются через `/v1/models` с `owned_by: "combo"`, но **НЕ** через `/api/integrations/providers/with-models`, который использует CollectorService.

## Решение

**Вариант Б (модификация 9Router):** Добавить combos в ответ `/api/integrations/providers/with-models` как специальный provider connection с `provider: "combo"`.

---

## Изменения

### 1. F9Router: `/api/integrations/providers/with-models` ✅ ВЫПОЛНЕНО

**Файл:** `C:\Programs\F9Router\src\app\api\integrations\providers\with-models\route.js`

**Изменения:**
- Добавлен импорт `getCombos` из `@/lib/localDb`
- После сбора provider connections, добавляется specials connection для combos:
  ```javascript
  {
    id: "__combos__",
    provider: "combo",
    authType: "none",
    name: "Combos",
    isActive: true,
    testStatus: null,
    models: combos.map(combo => ({
      id: combo.name,        // "MimoCombos"
      publicId: combo.name,  // "MimoCombos"
      name: combo.name,
      type: "combo",
      enabled: true
    }))
  }
  ```

**Результат:** Теперь `/api/integrations/providers/with-models` отвечает:
```json
{
  "connections": [
    ...provider connections...,
    {
      "id": "__combos__",
      "provider": "combo",
      "name": "Combos",
      "isActive": true,
      "models": [
        { "id": "MimoCombos", "publicId": "MimoCombos", "name": "MimoCombos", "type": "combo", "enabled": true }
      ]
    }
  ]
}
```

### 2. CollectorService: обработка combo моделей — НЕ ТРЕБУЕТ ИЗМЕНЕНИЙ

Текущий код в `NodeCatalogCollector.CollectAsync` уже корректно обрабатывает combo:

```csharp
foreach (var connection in providersWithModels.Connections)
{
    if (!connection.IsActive || string.IsNullOrWhiteSpace(connection.Id))
        continue;  // "__combos__" проходит проверку
    foreach (var model in connection.Models)
    {
        if (string.IsNullOrWhiteSpace(model.Id) || !model.Enabled)
            continue;  // "MimoCombos" проходит проверку
        observations.Add(new ModelObservation
        {
            UpstreamId = model.Id,           // "MimoCombos"
            PublicId = model.PublicId,        // "MimoCombos"
            ModelType = model.Type,           // "combo"
            Provider = connection.Provider,   // "combo"
            ConnectionId = connection.Id,     // "__combos__"
            Rank = 2
        });
    }
}
```

### 3. CatalogProjection: combo попадает в capability store — НЕ ТРЕБУЕТ ИЗМЕНЕНИЙ

`GetRoutableModelId(observation)` вернёт `PublicId` ("MimoCombos") → combo будет в списке routable model IDs ноды → `NodeModelCapabilityStore` подхватит.

### 4. ControlPlane: capability-aware routing — НЕ ТРЕБУЕТ ИЗМЕНЕНИЙ

`SelectRouterNodeAsync(modelId: "MimoCombos")` проверит `capabilityStore.NodeSupportsModel(nodeId, "MimoCombos")` → true → нода будет выбрана.

### 5. ApiGateway: forwarding на ноду — НЕ ТРЕБУЕТ ИЗМЕНЕНИЙ

`sdkRequestPatcher.PatchModel(json, "MimoCombos")` → запрос уходит на ноду → 9Router обрабатывает combo с fallback.

### 6. BillingService: создание billing модели — НЕ ТРЕБУЕТ ИЗМЕНЕНИЙ

Через WebApp admin `/admin/models?action=add`:
- Model ID: `mimo-combos`
- Router Model: `MimoCombos` (выбрать из dropdown)

## Что нужно сделать в OpenRussiaRouter (остаток)

### Задача A: Пересобрать и задеплоить 9Router

```bash
cd C:\Programs\F9Router
npm run build
# Задеплоить в k8s (образ обновится через Argo CD Image Updater)
```

### Задача B: Проверить что collector подхватывает combo

После деплоя 9Router, проверить логи collector'а:
```bash
kubectl logs orr-dev/collector-... --tail=200 | grep -i combo
```

Или проверить через curl к нode:
```bash
curl -H "Authorization: Bearer <control_token>" http://f9router/api/integrations/providers/with-models | jq '.connections[] | select(.provider == "combo")'
```

### Задача C: Импортировать combo через Models Sync

1. Открыть `/admin/models/sync`
2. Комбо "MimoCombos" должно появиться в "New On Nodes"
3. Ввести prefix (напр. `orr/`), отметить combo, нажать "Import Selected"

### Задача D: Протестировать end-to-end

```bash
curl -X POST http://localhost/v1/chat/completions \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "orr/mimo-combos", "messages": [{"role": "user", "content": "Hello"}]}'
```
