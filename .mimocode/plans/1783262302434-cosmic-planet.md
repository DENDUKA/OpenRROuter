# Plan: Улучшение фильтров на странице /admin/requests

## Goal
Заменить текущие текстовые фильтры (model, provider) на multi-select tag-фильтры для 5 полей (API Key, Model, Node, Provider, Account) + добавить кнопку Calculate для агрегации.

## Current state
- Фильтры: текстовые input для model/provider (точное совпадение `=`), datetime from/to
- Нет фильтров по API Key, Node, Account
- SQL: `a.model_id = @ModelFilter` — точное совпадение
- Keyset pagination (cursor `{createdAtUtc:O}|{requestId}`)

## Architecture: full stack change

**File:** `src/OpenRussiaRouter.Contracts/Protos/billing.proto`

Add repeated string fields to `ListAdminRequestsRequest`:

### 9. Razor View — Tag Filter UI
**File:** `src/OpenRussiaRouter.WebApp/Pages/Admin/Requests.cshtml`

Replace current text inputs with tag-style multi-select UI:

**UX Design:**
- Each filter field shows a row with label + available values as clickable tags
- Clicking a value toggles it in the filter (adds if absent, removes if present)
- Selected values shown as highlighted/active tags
- "Filter" button submits form with all selected values
- "Clear" button resets all filters
- Available values computed from current Records (distinct values)

**HTML structure per filter field:**
```html
<div class="adm-filter-group">
    <label>API Key</label>
    <div class="adm-filter-tags">
        @foreach (var val in Model.DistinctApiKeyPrefixes)
        {
            var isSelected = Model.ApiKeyPrefixFilters?.Contains(val) == true;
            <button type="button" class="adm-filter-tag @(isSelected ? "active" : "")"
                    data-field="apiKeyPrefix" data-value="@val">@val</button>
        }
    </div>
</div>
<!-- Hidden inputs to carry selected values in form -->
<input type="hidden" name="apiKeyPrefix" value="..." />
```

**JavaScript (inline or small script):**
- Toggle filter tag on click (add/remove from hidden input)
- Maintain state across tag clicks before form submit
- "Filter" button serializes all selected values to URL params
