# AGENTS.md

> **IMPORTANT**: ALWAYS respond to the user in Russian (Всегда отвечай на русском языке).

Инструкции для агентов в этом репозитории живут в **[CLAUDE.md](CLAUDE.md)** — это
единственный источник истины: build/test-инварианты, архитектура, поток запроса
через ApiGateway, два типа токенов 9Router, граница ответственности деплоя.

У каждого проекта в `src/` есть свой `CLAUDE.md` с деталями конкретного сервиса —
читай его перед правкой этого сервиса.

## Маркетинг и память агентов (`marketing/MarketingMemory.md`)

- **Если задача или обсуждение касается маркетинга** (Яндекс Директ, контекстная реклама, SEO, каналы привлечения, промо-акции, конверсии, гипотезы):
  1. **Перед работой** — прочитай `marketing/MarketingMemory.md` (контекст, прошлые результаты, ошибки).
  2. **После работы/обсуждения** — обязательно дополни `marketing/MarketingMemory.md` (что сделано, настройки, цифры и метрики, что пошло не так, выводы для будущих агентов).
