# Обработка ошибок

В случае ошибки API возвращает ответ в стандартном формате JSON с соответствующим HTTP статусом (4xx или 5xx).

## Формат ошибки

```json
{
  "error": {
    "code": "insufficient_balance",
    "message": "Недостаточно средств на балансе для выполнения запроса.",
    "type": "billing_error"
  }
}
```

## Стандартные коды ошибок

| Код ошибки | Описание |
|---|---|
| `authentication_required` | Отсутствует заголовок Authorization |
| `invalid_api_key` | Неверный или отозванный API-ключ |
| `insufficient_balance` | Отрицательный баланс (для платных моделей) |
| `api_key_limit_exceeded` | Превышен лимит расходов для данного ключа |
| `model_unavailable` | Запрошенная модель отключена или не найдена |
| `router_unavailable` | Нет доступных нод для обработки запроса (upstream) |
| `validation_failed` | Ошибка валидации JSON-тела запроса |
| `rate_limited` | Слишком много запросов |
| `internal_error` | Внутренняя ошибка платформы |

## Ошибки Upstream

Если ошибка произошла на стороне провайдера модели (например, OpenAI или Anthropic) после успешной маршрутизации запроса шлюзом, Rawrter проксирует эту ошибку клиенту в оригинальном виде.
