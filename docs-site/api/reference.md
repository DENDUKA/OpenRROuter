# Обзор API

Rawrter предоставляет OpenAI-совместимый API. Все эндпоинты доступны по базовому URL:

```
https://api.rawrter.com
```

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/v1/chat/completions` | Генерация ответов модели (с поддержкой streaming). |
| `POST` | `/v1/chat/completions/stream` | Явный alias для streaming-ответов. |
| `GET` | `/v1/models` | Получение списка доступных моделей. |

## Идентификатор корреляции

Каждый ответ от API включает заголовки для трейсинга и дебага:
- `X-Correlation-Id`
- `X-Request-Id`

Если вы обращаетесь в поддержку с проблемой, пожалуйста, приложите значение `X-Correlation-Id` из проблемного ответа.
