# Управление API ключами

API ключ — это ваш идентификатор для доступа к Rawrter API. Один ключ работает со всеми моделями.

## Создание ключа

1. Перейдите в панель управления.
2. В разделе "API ключи" нажмите создать.
3. Скопируйте сгенерированный ключ (формат `sk-or-<36 случайных символов>`).

::: warning Сохраните ключ
Полный ключ (raw) показывается только один раз при создании. В нашей базе данных сохраняется только его безопасный SHA-256 хеш. Если вы потеряли ключ, вам придется его отозвать и создать новый.
:::

## Формат ключа

Все ключи Rawrter начинаются с префикса `sk-or-`. Используйте ключ в заголовке `Authorization` при отправке HTTP-запросов:

```http
Authorization: Bearer sk-or-xxx
```

## Безопасность

- **Не коммитьте ключи в код.** Используйте переменные окружения (`.env`).
- **Своевременно отзывайте ключи**, если подозреваете, что они были скомпрометированы.
- Вы можете создать несколько ключей для разных проектов или сред разработки.
