# Баланс и биллинг

Rawrter использует единую систему предоплаченного биллинга в **долларах США (USD)**.

## Как работает списание

Списание средств происходит автоматически после каждого успешного запроса к модели на основе фактически использованных токенов (Token Usage).

Формула расчета стоимости запроса:

`Стоимость = (InputTokens * InputPrice + OutputTokens * OutputPrice + CacheTokens * CachePrice) / 1,000,000`

### Особенности учета токенов

- **Кэширование промптов (Prompt Caching):** Ведущие модели (Anthropic Claude, DeepSeek, OpenAI) поддерживают автоматическое кэширование повторяющихся префиксов промпта (системные инструкции, файлы документации, длинная история диалога). Токены, прочитанные из кэша, тарифицируются по сниженной цене `CachePrice` (часто в 2–10 раз дешевле обычных входящих токенов). В формуле списания кэшированные токены вычитаются из общих входных токенов:
  ```
  Базовые токены = max(0, InputTokens - CacheTokens)
  Стоимость = (Базовые токены * InputPrice + OutputTokens * OutputPrice + CacheTokens * CachePrice) / 1,000,000
  ```
- **Округление:** Округление происходит до 6 знаков после запятой (микроценты).
- **Бесплатные модели:** Для моделей с нулевой стоимостью входных и выходных токенов запросы выполняются даже при нулевом балансе.

## Пополнение баланса

Пополнение баланса осуществляется через личный кабинет. Конвертация в USD происходит по актуальному курсу на момент зачисления средств.

В личном кабинете вы можете выбрать удобную валюту отображения (Display Currency), например, рубли (RUB) или евро (EUR) — пересчет происходит автоматически с использованием актуальных курсов.

## Ошибки при нулевом балансе

Если ваш баланс опустится ниже нуля, API начнет возвращать ошибку `insufficient_balance` (HTTP 402 / 400).
