# Список моделей

Для получения актуального списка моделей используйте эндпоинт API:

`GET /v1/models`

В ответ вернется список моделей, доступных для вашего аккаунта, в формате, совместимом с OpenAI.

## Формат ответа API

```json
{
  "object": "list",
  "data": [
    {
      "id": "gpt-4o",
      "object": "model",
      "created": 1715367049,
      "owned_by": "openai"
    },
    {
      "id": "claude-3-5-sonnet",
      "object": "model",
      "created": 1718841600,
      "owned_by": "anthropic"
    }
  ]
}
```

*Обратите внимание: Идентификатор `id` из ответа — это то значение, которое необходимо передавать в параметре `model` при создании запроса в `/v1/chat/completions`.*
