## Ограничения точных границ

Границы b−1/b/b+1 запрошены у всех указанных CSS b. Некоторым нечётным b+1 среда присвоила innerWidth на 1 px больше — помечено rounded в CSV. Эти точные пиксели не проверены; смежная сторона проверена. Список в основном отчёте. Для страниц, где нет данного breakpoint, соответствующее правило не применимо: не создавались фиктивные проверки.
