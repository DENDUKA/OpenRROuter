# Политика конфиденциальности Web Point Gateway

Дата актуализации: 19.05.2026

Настоящая Политика конфиденциальности определяет порядок обработки информации пользователей сервиса Web Point Gateway, сокращенно WPG.

## 1. Общие положения

1.1. WPG предоставляет пользователям доступ к сервису защищенного сетевого подключения, управлению подпиской, ключами подключения, платежами и технической поддержкой через официальный интерфейс сервиса, включая Telegram-бота WPG и иные опубликованные каналы.

1.2. Настоящая Политика разработана с учетом Федерального закона от 27.07.2006 N 152-ФЗ "О персональных данных" и применимого законодательства Российской Федерации.

1.3. Используя WPG, Пользователь подтверждает, что ознакомился с настоящей Политикой и принимает ее условия.

1.4. Если Пользователь не согласен с условиями Политики, он должен прекратить использование WPG.

1.5. WPG не запрашивает у Пользователя паспортные данные, адрес регистрации, сведения о доходах и иные избыточные данные, не требующиеся для предоставления сервиса.

## 2. Термины

2.1. Сервис, WPG - Web Point Gateway, программно-технический комплекс для предоставления защищенного сетевого подключения и управления пользовательскими подписками.

2.2. Пользователь - физическое лицо, использующее WPG.

2.3. Оператор - лицо, администрирующее WPG и организующее обработку данных в целях предоставления сервиса.

2.4. Технические данные - сведения, необходимые для регистрации, авторизации, предоставления подписки, формирования ключей подключения, учета оплаты, поддержки и обеспечения безопасности.

2.5. Подписочный токен - уникальная техническая строка, используемая для выдачи Пользователю актуальных параметров подключения.

2.6. Обработка данных - сбор, запись, систематизация, хранение, уточнение, использование, блокирование, удаление и иные действия с данными, необходимые для работы WPG.

## 3. Какие данные обрабатывает WPG

3.1. При использовании WPG могут обрабатываться следующие категории данных:

- числовой идентификатор Telegram-аккаунта;
- Telegram username, если он доступен;
- статус Пользователя в сервисе, дата регистрации, дата обновления профиля, дата окончания подписки;
- подписочный токен, версия конфигурации, технические ключи и параметры подключения;
- сведения о назначенных серверных узлах и состоянии синхронизации доступа;
- счетчики использованного и доступного трафика, если они применяются выбранным тарифом или технической инфраструктурой;
- email-адрес, если Пользователь добровольно привязывает его как резервный канал доставки параметров подключения;
- временные данные подтверждения email: код в хешированном виде, срок действия кода, количество попыток и время отправки;
- сведения о платежах: сумма, валюта, способ оплаты, статус платежа, срок действия заявки, код платежа, идентификатор транзакции при наличии, зафиксированный курс при оплате цифровыми активами;
- служебные данные обращений в поддержку: идентификаторы сообщений и переписок, необходимые для ответа Пользователю;
- технические журналы работы сервиса, включая ошибки, события мониторинга, состояние серверных узлов и результаты проверок доступности.

3.2. Числовой идентификатор Telegram-аккаунта хранится в двух формах:

- HMAC-хеш для поиска Пользователя в базе данных;
- зашифрованное значение для отправки сервисных уведомлений.

3.3. Email-адрес, если Пользователь его добавил, также хранится в двух формах:

- HMAC-хеш для проверки уникальности и поиска;
- зашифрованное значение для отправки параметров подключения и сервисных писем.

3.4. WPG не хранит реквизиты банковских карт. При использовании сторонних платежных инструментов обработка платежных реквизитов выполняется соответствующим платежным сервисом, банком, оператором перевода, платежным агрегатором или сетью цифровых активов.

3.5. При оплате через платежного агрегатора WPG передает агрегатору минимально необходимый набор сведений для проведения платежа: сумму, валюту, идентификатор платежной заявки, описание платежа и технический идентификатор учетной записи Пользователя. Платежные реквизиты, передаваемые Пользователем агрегатору на его платежной странице, WPG не получает и не хранит.

3.6. WPG не обрабатывает содержимое интернет-трафика Пользователя и не ведет журнал посещенных Пользователем сайтов.

## 4. Цели обработки данных

4.1. Данные обрабатываются для следующих целей:

- регистрация Пользователя в WPG;
- автоматическая авторизация и поиск учетной записи;
- предоставление тестового или платного доступа;
- формирование, обновление и перевыпуск параметров подключения;
- управление подпиской, сроком действия услуг и тарифом;
- учет статуса платежей и автоматическое либо ручное подтверждение оплаты;
- доставка уведомлений о статусе подписки, оплате, технических изменениях и доступности сервиса;
- привязка email как резервного канала доставки параметров подключения;
- обработка обращений в поддержку;
- предотвращение злоупотреблений и несанкционированного доступа;
- диагностика технических ошибок и поддержание стабильной работы инфраструктуры;
- ведение обезличенной статистики и улучшение качества WPG.

## 5. Правовые основания обработки

5.1. Обработка данных осуществляется на основании:

- акцепта Пользователем публичной оферты WPG;
- необходимости исполнения договора с Пользователем;
- согласия Пользователя на обработку данных, когда такое согласие требуется;
- законных интересов Оператора по обеспечению безопасности, устойчивости и корректной работы WPG;
- требований применимого законодательства.

5.2. Пользователь вправе отозвать согласие на обработку данных, если такая обработка основана на согласии. Отзыв согласия может сделать невозможным дальнейшее предоставление отдельных функций или всего сервиса.

## 6. Хранение и удаление данных

6.1. Данные хранятся не дольше, чем это необходимо для целей обработки, исполнения договора, выполнения требований законодательства и защиты прав Оператора.

6.2. Данные активной учетной записи хранятся в течение срока использования WPG.

6.3. После прекращения использования WPG Пользователь вправе запросить удаление связанных с ним данных через поддержку сервиса.

6.4. Технические данные, необходимые для подтверждения факта оказания услуг, платежей, разрешения споров, предотвращения злоупотреблений или выполнения требований закона, могут храниться в течение необходимого срока.

6.5. Временные данные подтверждения email удаляются или перезаписываются после успешного подтверждения, истечения срока действия кода или превышения допустимого количества попыток.

6.6. Обезличенная техническая статистика может храниться после удаления учетной записи, если она не позволяет идентифицировать Пользователя.

## 7. Защита данных

7.1. WPG применяет организационные и технические меры защиты данных, включая:

- хранение чувствительных идентификаторов в HMAC- и зашифрованном виде;
- разграничение доступа к административным функциям;
- ограничение доступа к служебным интерфейсам;
- резервное копирование и технический мониторинг;
- журналирование служебных событий без раскрытия полных секретных ключей и токенов;
- использование защищенных каналов администрирования инфраструктуры.

7.2. Доступ к данным предоставляется только лицам и сервисам, которым он необходим для работы WPG, поддержки Пользователей, обработки платежей, администрирования и обеспечения безопасности.

## 8. Передача данных третьим лицам

8.1. WPG может передавать или раскрывать данные третьим лицам только в следующих случаях:

- Пользователь дал согласие на такую передачу;
- передача необходима для исполнения договора с Пользователем;
- передача необходима для обработки платежа, в том числе через платежного агрегатора, доставки email, работы хостинга, инфраструктуры или технической поддержки;
- передача требуется по законному запросу уполномоченного государственного органа;
- передача необходима для защиты прав и законных интересов Оператора.

8.2. WPG не продает данные Пользователей и не передает их третьим лицам для самостоятельной рекламной рассылки.

## 9. Права Пользователя

9.1. Пользователь вправе:

- получить информацию об обработке своих данных;
- запросить уточнение, блокирование или удаление данных;
- отказаться от дальнейшего использования WPG;
- отозвать согласие на обработку данных, если применимо;
- обратиться в поддержку по вопросам конфиденциальности и безопасности.

9.2. Для реализации прав Пользователь направляет запрос через официальный интерфейс WPG, раздел поддержки или иной опубликованный канал связи.

9.3. Оператор вправе запросить дополнительную информацию, необходимую для подтверждения принадлежности запроса конкретной учетной записи.

## 10. Изменение Политики

10.1. WPG вправе изменять настоящую Политику при изменении законодательства, функциональности сервиса, инфраструктуры, платежных способов или порядка обработки данных.

10.2. Новая редакция Политики вступает в силу с момента публикации в официальном интерфейсе WPG, если иной срок не указан в самой редакции.

10.3. Продолжение использования WPG после публикации новой редакции означает согласие Пользователя с изменениями.

## 11. Контакты

11.1. По вопросам обработки данных, удаления учетной записи, безопасности и реализации прав Пользователь может обратиться в поддержку через официальный интерфейс WPG.

11.2. Дополнительные контактные данные Оператора, если они предусмотрены, публикуются в интерфейсе WPG или в разделе юридических документов.
