# Анализ поискового спроса для OpenRussiaRouter

Дата исследования: 12 июля 2026 года.

Источник: [Яндекс Вордстат](https://wordstat.yandex.ru/).

Настройки выборки:

- регион — Россия (`region=225`);
- устройства — десктопы, смартфоны и планшеты;
- основной период — 11 июня – 10 июля 2026 года;
- для динамики OpenRouter — июль 2024 – июнь 2026 года.

## 1. Задача исследования

Оценить, сколько поисковых запросов в России связано с услугой
OpenRussiaRouter: доступом к API зарубежных LLM, получением API-ключей, оплатой
из России и использованием агрегатора моделей, аналогичного OpenRouter.

Целевая аудитория:

- разработчики;
- небольшие AI-команды;
- AI-энтузиасты;
- пользователи OpenRouter, которым нужна оплата российской картой или
  альтернативный сервис.

## 2. Важное ограничение Wordstat

Wordstat показывает число запросов, а не число уникальных людей. Один человек
может выполнить несколько похожих запросов. Кроме того, широкая частотность
включает вложенные формулировки, информационный спрос, поиск документации,
ошибок и бесплатных ключей.

Поэтому:

- частотности разных кластеров нельзя просто складывать как число людей;
- строки внутри одного кластера пересекаются с его общей частотностью;
- расчёт уникальной аудитории и коммерческого спроса ниже является оценкой, а
  не фактическим показателем Wordstat.

Механическая сумма этих кластеров — 30 800 запросов. Она не равна размеру
аудитории из-за пересечений и информационного спроса.

Расчётная оценка после поправки на пересечения и нецелевые формулировки:

- 22–28 тыс. релевантных запросов в месяц;
- 13–20 тыс. отдельных заинтересованных пользователей в месяц;
- 2–4 тыс. запросов с выраженным коммерческим намерением;
- 1,5–3 тыс. пользователей в месяц, которые могут выбирать сервис, способ
  оплаты или альтернативу.

Оценка уникальных пользователей построена на предположении, что один человек
выполняет в среднем несколько связанных запросов. После запуска рекламы её
необходимо заменить фактическими данными Метрики и Директа.

## 9. Выводы для позиционирования

Наиболее перспективные направления:

1. Альтернатива OpenRouter с оплатой в России.
2. Claude API и Claude Code с понятным способом оплаты.
3. Gemini API с российской картой без обещания бесплатного официального ключа.
4. DeepSeek API: оплата, пополнение и использование из России.
5. OpenAI-совместимый API для разработчиков.

Главный вывод: рынок формулирует потребность через названия OpenRouter и
конкретных моделей. Абстрактный оффер «единый API для нейросетей» понятен
продуктово, но слишком слаб как основной поисковый запрос.

Рекомендованный основной оффер для теста:

> API ведущих AI-моделей с оплатой российской картой. Единый
> OpenAI-совместимый интерфейс, рублёвый баланс и стартовый кредит для проверки
> подключения.

Для конкурентного кластера:

> Альтернатива OpenRouter для России: модели через единый API, оплата в рублях и
> поддержка на русском языке.

Утверждение о ценах ниже OpenRouter можно использовать только при наличии
публичного сравнения одинаковых моделей с датой обновления.

## 10. Предварительная оценка достижимости цели

Цель — 100 пользователей с первым платным пополнением за три месяца.

При расчётной коммерческой аудитории 1,5–3 тыс. пользователей в месяц за три
месяца рынок даёт приблизительно 4,5–9 тыс. потенциально подходящих людей. Для
100 первых оплат потребуется привлечь и конвертировать примерно 1,1–2,2% этой
трёхмесячной аудитории.

Это достижимо для комплекса каналов, но агрессивно для одного Яндекс Директа.
Фактический результат будет зависеть от:

- доли показов объявлений;
- CPC и рекламного бюджета;
- CTR;
- конверсии перехода в регистрацию;
- доли подтвердивших email;
- доли выполнивших первый API-запрос;
- конверсии активированного пользователя в первое пополнение.

До запуска нельзя считать расчёт Wordstat прогнозом продаж.
