## 1. Как читать эти цифры

Три ограничения, без которых любой вывод ниже будет прочитан неверно.

**Вордстат считает запросы, а не людей.** Один человек за месяц вводит 2–4 связанные
формулировки. Число людей всегда меньше числа запросов.

**Строки внутри кластера вложены друг в друга.** `claude code api key` (1 194) целиком входит
в `claude code api` (1 911), а тот — в `claude code` (62 774). Складывать строки одного кластера
нельзя: получится двойной счёт. Везде ниже, где стоит сумма, сложены только непересекающиеся
маркеры, и это оговорено.

**Общая частотность включает мусор.** У `cursor` 180 993 запроса, но подавляющая часть — это
курсоры мыши, скины для osu и Roblox. У `codex` 110 965, и внутри — читерский экзекьютор для
Roblox и кодексы Warhammer 40000. Брать общую частотность такого кластера за размер рынка —
самая дорогая ошибка, которую можно совершить перед запуском Директа.

## 5. Сколько это потенциальных клиентов

### 5.1. Из запросов в людей

Один человек в этой теме за месяц вводит 2–4 связанные формулировки («claude code в россии»,
«как оплатить claude code», «аналоги claude code» — это чаще всего один и тот же человек).

**18–23 тыс. адресуемых запросов → 6–10 тыс. уникальных людей в месяц** с намерением платить
за доступ к зарубежным LLM.

Это размер рынка, а не размер вашей доли: те же люди видят ProxyAPI, перепродавцов ключей
на GGSel и FunPay, VPN-обходы и советы в Telegram-чатах.

**Главный вывод, который меняет прежний план: спроса хватает.** Июльская оценка давала потолок
в 7–41 платящего за квартал и вывод «горячей семантики физически не хватает». После замера

Оговорка, без которой таблица опасна: конверсии в ней — гипотезы. Единственная цифра,
измеренная фактически, — частотности. Первые 100–150 кликов заменят вторую половину таблицы
реальными данными, и пересчитать её надо сразу же.

## 8. Находки, которых не было в прошлом анализе

**1. Кластер блокировок OpenRouter — около 1 300 запросов в месяц.** Это принципиально новое
явление: конкурент перестал открываться из России. Человек в этот момент максимально готов
уйти. Но здесь же и главный риск: формулировки «обход блокировок», «доступ к заблокированному»,
«без VPN» — прямой отказ модерации Директа. Безопасная подача — говорить о своём сервисе,
а не о чужой блокировке: «Российский сервис. Сайт и API открываются без ухищрений».

**2. Люди покупают ключи на игровых маркетплейсах.** `ggsel openrouter` 119,
`claude api funpay` 18, `claude api ggsel` 12, `funpay deepseek api` 11. Это отдельный канал
дистрибуции, который сейчас забирает часть спроса, и одновременно подтверждение готовности
платить рублями за доступ.

**3. `claude code router` 119 и `claude code openrouter` 107** — люди ищут ровно то, чем
является наш продукт, называя его почти нашим именем. Микрообъём, но идеальное совпадение.

**4. `openai совместимый llm api в россии` — 159 запросов.** Это дословное описание продукта.
Конкуренция по такой фразе почти нулевая, клик будет дешёвым.

**5. Codex вырос до сопоставимого с Claude Code масштаба**, но остаётся неразделим с Roblox-читом
того же названия. Пока не появится статистика по поисковым запросам из самого Директа,
относиться к нему как к эксперименту, а не как к опоре.

**6. Cursor-аудитория ищет подписку, а не ключ.** Внутри `cursor оплата` (387) сплошь
«карта для оплаты», «виртуальная карта». Это не наша потребность, и попытка продать им
API-ключ даст возвраты. Отсюда коэффициент 0,3.
