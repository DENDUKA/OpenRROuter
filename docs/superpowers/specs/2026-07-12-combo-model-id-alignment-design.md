# Выравнивание Model ID с Combo Router Model

## Цель

Для всех карточек, маршрутизируемых через целевые Combo-алиасы, `Model ID`
должен в точности совпадать с `Router Model`.

## Границы

- Изменяются только строки `billing.model_prices` целевого списка Combo.
- Сохраняются цены, описания, модальности, доступность, приоритеты и провайдеры.
- Исторические таблицы использования и бухгалтерские записи не переписываются:
  они остаются неизменяемым аудитом уже обработанных запросов.
- Не затрагивается отдельная карточка `GLM-5.2`, которую пользователь исключил
  из списка.

## Подход

Одна транзакция PostgreSQL сначала проверяет отсутствие коллизий, затем меняет
`model_id` у 16 карточек, которым требуется выравнивание. Две уже совпадающие
карточки не изменяются. Изменение первичного ключа безопасно: в схеме нет
внешних ключей на `billing.model_prices.model_id`.

## Проверка

После транзакции запрос по 18 целевым Combo должен подтвердить для каждой
карточки: `model_id = router_model_id`, ровно одну карточку, включённый статус,
заданные цены, описания на русском и английском, а также входные и выходные
модальности.
