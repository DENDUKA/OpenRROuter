# T-009: корректная keyset-пагинация AuthRepository

Сохранить существующие сигнатуры cursor API, но в PostgreSQL связать cursor id с его фактическим ключом сортировки. Для пользователей и API-ключей вторая страница должна фильтроваться лексикографически по `(created_at_utc, id)` относительно записи cursor, затем сортироваться тем же ключом по убыванию. Добавить PostgreSQL-регрессионные тесты на две страницы без дублей и пропусков. In-memory реализация уже использует позицию cursor в отсортированной последовательности и должна сохранить контракт.
