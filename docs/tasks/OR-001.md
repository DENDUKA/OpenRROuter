# OR-001: Настраиваемое число локальных backup'ов 9Router

Complexity: 3/10
Model: GPT-5.5 Codex (High)
Review: Claude Opus 4.7 (Extra High)
Dependencies: Нет

## Prompt

Сделать количество локальных SQLite backup'ов 9Router управляемым через env-переменную `BACKUPS_KEEP_COUNT`, с дефолтом `1`, без добавления UI и без зависимости `backup.js` от БД.

## Файлы

- `src/OpenRussiaRouter.9Router/src/lib/db/backup.js` (изменить)
- `src/OpenRussiaRouter.9Router/src/lib/db/migrate.js` (изменить)
- `src/OpenRussiaRouter.9Router/.env.example` (изменить)

## Что нужно сделать

### 1. Убрать захардкоженный `KEEP_BACKUPS = 5`

В `backup.js` заменить константу на параметр функции:

- `pruneOldBackups(maxKeep)`
- `maxKeep = 1` как безопасный fallback внутри функции, если вызывающий код передал невалидное значение.

Значения:

- `0` означает удалить все старые backup-директории после очередного backup'а;
- отрицательные, `NaN`, пустые и нечисловые значения трактовать как `1`;
- дробные значения округлять вниз.

Inline-правку пометить маркерами:

```js
// ORR-PATCH BEGIN: configurable local backup retention
// ...
// ORR-PATCH END
```

### 2. Читать `BACKUPS_KEEP_COUNT` в `migrate.js`

В `migrate.js` добавить локальный helper для чтения env:

- читает `process.env.BACKUPS_KEEP_COUNT`;
- применяет те же правила валидации;
- возвращает число.

Во всех текущих вызовах `pruneOldBackups()` передавать это значение явно.

### 3. Не добавлять UI и settings-зависимость

Не читать `settings` из таблицы БД и не импортировать `getAdapter()` / `settingsRepo.js` в `backup.js`.

Причина: `backup.js` должен остаться простым `fs`-модулем, а настройка нужна только на старте миграционного сценария.

### 4. Обновить `.env.example`

Добавить документированную переменную:

```env
# Local SQLite migration/upgrade backups to keep under DATA_DIR/db/backups.
# 0 disables keeping local backups after pruning. Default in code: 1.
BACKUPS_KEEP_COUNT=1
```

## Что НЕ менять

- Не менять момент создания backup'ов.
- Не переносить backup до миграций в рамках этой задачи.
- Не добавлять UI-поле.
- Не менять структуру директории `DATA_DIR/db/backups`.

## Критерии готовности

- `backup.js` больше не содержит фиксированное `KEEP_BACKUPS = 5`.
- `migrate.js` передаёт `maxKeep` во все вызовы `pruneOldBackups`.
- При `BACKUPS_KEEP_COUNT=1` остаётся только одна самая свежая backup-директория.
- При `BACKUPS_KEEP_COUNT=0` старые backup-директории удаляются при pruning.
- `.env.example` содержит `BACKUPS_KEEP_COUNT`.
- Сборка 9Router проходит стандартной командой проекта или в отчёте указана причина, почему она не запускалась.
