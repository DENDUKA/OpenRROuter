# OR-004: Observability defaults и корректный env fallback

Complexity: 4/10
Model: GPT-5.5 Codex (High)
Review: Claude Opus 4.7 (Extra High)
Dependencies: Нет

## Prompt

Понизить production-дефолты observability в 9Router и одновременно починить чтение env-переменных `OBSERVABILITY_*`, чтобы схема стала `raw settings ?? env ?? code default`, а не теряла env из-за `mergeWithDefaults()`.

## Файлы

- `src/OpenRussiaRouter.9Router/src/lib/db/repos/settingsRepo.js` (изменить)
- `src/OpenRussiaRouter.9Router/src/lib/db/repos/requestDetailsRepo.js` (изменить)
- `src/OpenRussiaRouter.9Router/.env.example` (изменить)

## Что нужно сделать

### 1. Изменить дефолты observability

В `DEFAULT_SETTINGS`:

- `observabilityMaxRecords`: `1000` → `200`
- `observabilityMaxJsonSize`: `5` → `2`

`enableObservability` оставить `true`.

### 2. Дать `requestDetailsRepo.js` доступ к raw settings

Сделать безопасный способ прочитать raw settings без подмешивания дефолтов.

Допустимые варианты:

- экспортировать из `settingsRepo.js` отдельную функцию `getRawSettings()`;
- или локально в `requestDetailsRepo.js` прочитать `SELECT data FROM settings WHERE id = 1`.

Главное требование: `getObservabilityConfig()` не должен использовать результат `getSettings()` для env fallback.

### 3. Починить порядок fallback

В `getObservabilityConfig()` применить схему:

```js
raw.enableObservability ?? envEnabled ?? defaultEnabled
raw.observabilityMaxRecords ?? envMaxRecords ?? DEFAULT_MAX_RECORDS
raw.observabilityBatchSize ?? envBatchSize ?? DEFAULT_BATCH_SIZE
raw.observabilityFlushIntervalMs ?? envFlushIntervalMs ?? DEFAULT_FLUSH_INTERVAL_MS
raw.observabilityMaxJsonSize ?? envMaxJsonSizeKb ?? DEFAULT_MAX_JSON_SIZE_KB
```

Требования:

- использовать `??`, а не `||`, чтобы не ломать явные false/0;
- числовые env значения валидировать: невалидные, отрицательные и `NaN` откатывать к default;
- `observabilityMaxJsonSize` в settings/env трактуется как КБ и умножается на `1024` перед truncate.

### 4. Обновить `.env.example`

Добавить:

```env
OBSERVABILITY_MAX_RECORDS=200
OBSERVABILITY_MAX_JSON_SIZE=2
OBSERVABILITY_BATCH_SIZE=20
OBSERVABILITY_FLUSH_INTERVAL_MS=5000
```

`OBSERVABILITY_ENABLED=true` уже есть — оставить.

## Что НЕ менять

- Не выключать observability по умолчанию.
- Не менять формат данных `requestDetails`.
- Не менять UI settings.
- Не менять retention `requestDetails` кроме новых default/config значений.

## Критерии готовности

- Новые дефолты в `settingsRepo.js`: `200` записей и `2` КБ.
- Если raw settings не содержит observability-поле, env-переменная реально влияет на конфиг.
- Если raw settings содержит observability-поле, оно имеет приоритет над env.
- `enableObservability=false` из raw settings или env корректно выключает запись.
- `.env.example` содержит недостающие `OBSERVABILITY_*`.
- Сборка 9Router проходит стандартной командой проекта или в отчёте указана причина, почему она не запускалась.
