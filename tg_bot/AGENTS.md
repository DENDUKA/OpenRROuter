# Rawrter Telegram Bot

- Общаться на русском. Следовать корневому `../CLAUDE.md` и `README.md` этого каталога.
- По решению владельца бот перенесён в `OpenRussiaRouter/tg_bot`; отдельный Node.js 24/TypeScript/Fastify сервис, не часть .NET solution.
- Проверки: `npm ci --ignore-scripts`, `npm run typecheck`, `npm test`, `npm run build`. Тесты только с синтетическими данными и подменёнными внешними транспортами.
- Без разрешения не выполнять deploy, перезапуски сервера, внешние тестовые отправки, подключение аккаунтов или изменение секретов.
- Не сохранять в Git секреты, реальные обращения и клиентские данные. Не копировать серверный `.env`. Не логировать токены, адреса и тексты сообщений.
- Не создавать отдельную БД для бота. Если в будущем понадобится доступ к существующей БД openrussiarouter — только чтение с минимальными правами, отдельная задача. Сейчас статистика поступает через закрытый HTTP API WebApp.
- Очередь и дедупликация остаются best-effort в памяти. Чтение бизнес-данных не восстанавливает статусы доставки и не заменяет outbox.
- Не добавлять новые команды, топики и ответы клиентам как сопутствующую правку. В текущей версии Telegram updates не принимаются.
- Бэклог миграции — корневой `.opencode/tasks.md`; прежние BOT-002–004 находятся в исходном пространстве rawrter_tg_bot_support и не считаются завершёнными переносом.
